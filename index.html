How this is calculated
This shows the percentage of forward curve data points (non-interpolated, i.e. backed by actual market data) whose consensus temperature exceeds the Paris Agreement's 1.5°C target above pre-industrial levels.

For example, if 4 out of 5 market-implied data points are above 1.5°C, the breach probability is 80%.

Note: This is a simplified metric based on how many future years markets imply will exceed 1.5°C — it is not a formal probabilistic forecast. It covers only years where prediction market data exists.

Methodology

This tool aggregates data from three prediction markets — Polymarket, Metaculus, and Kalshi — to construct a forward-looking temperature anomaly curve. Binary markets (e.g., "Will 2026 be the hottest year?") provide implied probabilities for specific temperature thresholds. Continuous forecast questions (Metaculus) provide full probability distributions over expected anomaly values. All values are normalized to the pre-industrial (1850–1900) baseline.

The consensus forward curve is computed as a volume/participation-weighted average of implied temperature expectations from each source. Confidence bands represent the 10th–90th percentile range derived from market distributions and bracket probabilities. Historical data comes from NASA GISTEMP v4.

Note: Prediction market prices reflect trader sentiment and liquidity conditions, not climate model outputs. When live API calls encounter CORS restrictions, the application falls back to recent cached data and clearly indicates this in the source status.
